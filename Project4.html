Project Overview

This project involves the development of a backend healthcare system for Philips Healthcare, built using Spring Boot and a microservices architecture to ensure scalability, reliability, and maintainability. The system supports secure APIs for managing sensitive patient data and clinical workflows, with strong emphasis on data privacy, authentication, and payload validation using JSON and XML standards. The project follows an end-to-end development approach, including service design, implementation, CI/CD pipeline integration, deployment, and post-release support, enabling efficient and compliant healthcare operations.
